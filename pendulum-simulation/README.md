# 学者工坊

独立的中世纪学者工坊主题版本。原版项目代码、语言文件与启动脚本保持原样。

## 启动

双击上一层文件夹中的“启动学者工坊.bat”，或者在本文件夹执行：

```text
python workshop.py
```

只使用Python标准库，需Python附带的Tkinter。没有图片、网络或第三方包依赖。
导入和语言文件均相对于程序文件夹定位，不绑定本机盘符。

## 视觉与操作

- 羊皮纸面板、酒红色操作按钮、黄铜圆形滑块。
- 木制支架与黄铜摆球；运动、时间曲线、模拟周期和小角度公式比较。
- 四张探究卷页，自动统计数据进度，完成任务后显示绿色印章。
- 右上角切换简中、繁中、英文。切换语言保留动画状态、实验记录、预测与结论。
- 滑块支持拖动、方向键微调、Home/End定位。
- 任务页面右侧支持滚动，方便在较小窗口中填写结论和导出报告。
- CSV导出实验数据；JSON导出任务预测、结论和进度。关闭前请导出，当前不自动存档。
- 顶部“如何使用”页签（或F1）可打开内置三语言指引，包含快速上手、按键与滑块、任务清单、结果读法及保存与常见问题。

## 教学流程

在“探究卷册”选择一卷，填写预测，加载参数，开始模拟，测得周期后“记录本次实验”。
返回卷册检查数据并填写结论，点击“检查并完成当前任务”。卷二要求在运行前写下预测，首次运行后锁定。
卷三以偏差超过2%为课堂探究标准，不能据此认定普适的角度分界。

物理模型采用非线性单摆方程与固定步长四阶Runge–Kutta积分。表中的偏差是模拟周期相对小角度公式的差异，并非真实实验误差。

## 文件

- `workshop.py`：独立的工坊界面与绘图。
- `user_guide.py`：内置三语言操作指引，也用于生成离线使用指引。
- `使用指引.md`：可单独阅读的中文操作指引，与程序内指引使用同一份内容。
- `core.py`：从原版复制的物理模型和任务、记录逻辑。
- `language_support.py`、`translations.json`：独立的语言资源副本。

分享时请携带整个本文件夹；可直接执行 `workshop.py`。
